                    JAVA & SPRING BOOT - ENUM MİMARİSİ VE KULLANIM NOTLARI

1. ENUM NEDİR VE VERİ TİPİ OLARAK NASIL ÇALIŞIR?
--------------------------------------------------------------------------------
* Enum (Enumeration), Java'da `java.lang.Enum` sınıfından örtük (implicit) olarak
  türeyen özel bir referans veri tipidir (Class türüdür).
* Ne dinamik bir List (ArrayList) ne de bir HashSet'tir.
* Derleme anında (Compile-time) derleyici her bir sabiti (örn: SERVER, LAPTOP)
  o enum sınıfından türetilmiş tekil, değişmez (Singleton - public static final)
  bir nesneye dönüştürür.
* JVM bu sabitleri arka planda sabit boyutlu statik bir dizi içinde ($VALUES dizisi)
  saklar.
* Bellek ve işlem hızı açısından `==` ile doğrudan referans kontrolü yapıldığı
  için O(1) maliyetle çalışır.


2. NEDEN ENUM KULLANIYORUZ? (AMACIMIZ VE KAZANIMLARIMIZ)
--------------------------------------------------------------------------------
1) Tip Güvenliği (Type Safety):
   * Düz `String` kullanılsaydı metoda/API'ye "LAPTOOP", "SERVEER" gibi hatalı
     metinler gelebilir ve bu hata ancak veritabanına giderken fark edilirdi.
   * Enum ile sadece izin verilen sabit değerler (SERVER, LAPTOP, SWITCH, ROUTER)
     kabul edilir.

2) Otomatik Validasyon:
   * REST API Controller katmanında Jackson kütüphanesi gelen JSON içeriğini
     doğrudan Enum'a dönüştürür. Geçersiz değer geldiğinde istek iş mantığına
     ulaşmadan doğrudan HTTP 400 Bad Request ile engellenir.

3) Kod Okunabilirliği ve Bakım:
   * Kod içerisinde "magic string" ("ACTIVE", "SPARE") dolaşmasını engeller,
     if-else ve switch-case kontrollerini sadeleştirir.

4) API & Swagger Entegrasyonu:
   * Swagger / OpenAPI arayüzlerinde serbest metin kutusu yerine otomatik olarak
     açılır kutu (dropdown) sunulmasını sağlar.

5) MapStruct ve JPA Uyumu:
   * DTO ile Entity arasında ekstra mapleme kuralı yazmadan tip üzerinden
     birebir aktarım yapılmasını sağlar.


3. PROJEDE GENELDE NEREDE VE NASIL TANIMLANIR?
--------------------------------------------------------------------------------
Kurumsal katmanlı mimaride enum tipleri model katmanının altındaki özel bir pakette
toplanır:

* Dosya Konumu:
  src/main/java/com/neueprojekt/itam/model/enums/AssetType.java

* Tanımlama Kodu:
  package com.neueprojekt.itam.model.enums;

  public enum AssetType {
      SERVER,
      LAPTOP,
      SWITCH,
      ROUTER
  }

* Ek Enum Örneği (Statü Yönetimi için):
  package com.neueprojekt.itam.model.enums;

  public enum AssetStatus {
      ACTIVE,
      SPARE,
      MAINTENANCE,
      RETIRED
  }


4. ENUM'LAR PROJE KATMANLARINDA NASIL KULLANILIR?
--------------------------------------------------------------------------------
A) DTO (Data Transfer Object / Record) İçinde:
   public record AssetCreateRequestDto(
       String assetName,
       AssetType assetType,
       String ipAddress,
       String macAddress,
       String location
   ) {}

B) Entity / Model Katmanında (MSSQL Eşleşmesi):
   * Veritabanına ordinal (0, 1, 2) yerine okunabilir metin olarak yazılması
     için @Enumerated(EnumType.STRING) ile kullanılır.

   @Enumerated(EnumType.STRING)
   @Column(name = "asset_type", nullable = false, length = 50)
   private AssetType assetType;

C) Repository (Spring Data JPA) Katmanında:
   List<AssetModel> findByStatus(AssetStatus status);


5. VERİTABANI VE HIBERNATE EŞLEŞME (MAPPING) DİNAMİĞİ
--------------------------------------------------------------------------------
* Hibernate açılışta (ddl-auto=validate) SQL'deki VARCHAR(50) kolonu ile
  Java'daki EnumType.STRING tanımını doğrular.
* INSERT/UPDATE: Enum nesnesi `.name()` çağrısıyla VARCHAR kolona yazılır.
* SELECT: Tablodan okunan String değer `AssetType.valueOf("LAPTOP")` ile tekrar
  Java Enum nesnesine çevrilir. Tanımsız bir metin okunursa
  IllegalArgumentException fırlatılır.
================================================================================
"""

### 📌 Java & Spring Boot: Enum Mimarisi, Neden/Nasıl Kullanıldığı ve Veri Tipi Özeti

#### 1. Enum Nedir ve Veri Tipi Olarak Nasıl Saklanır?

* **Veri Tipi Tanımı:** Enum (`Enumeration`), Java'da `java.lang.Enum` sınıfından dolaylı türeyen **özel bir referans veri tipidir (Class türü)**.
* **Bellekteki Saklanma Mantığı:** Ne dinamik bir `List` ne de `HashSet`'tir. Derleme anında (Compile-time) derleyici her bir sabiti (örn: `SERVER`, `LAPTOP`) o sınıftan türetilmiş **tekil ve değişmez (`public static final`) birer nesneye** dönüştürür.


* JVM bu sabitleri arka planda sabit boyutlu statik bir dizi (`$VALUES[]`) içinde tutar. `==` operatörüyle bellek adresi üzerinden **$O(1)$** hızında kıyaslanır.

---

#### 2. Neden Enum Kullanıyoruz? (Ne İşimize Yarar?)

1. **Tip Güvenliği (Type Safety):** Metotlarda veya DTO'larda düz `String` yerine `AssetType` kullanarak metoda `"LAPTOOP"`, `"SERVERR"` gibi geçersiz/hatalı metinlerin gönderilmesini derleme seviyesinde engeller.


2. **Otomatik Validasyon:** Controller kapısında Jackson kütüphanesi gelen JSON'ı doğrudan enum tipine döker; geçersiz bir değer gelirse iş mantığına girmeden anında `400 Bad Request` döner.


3. **Magic String'lerden Kurtulma:** Kod içinde tırnak içinde metin kontrolleri (`if (type.equals("LAPTOP"))`) yerine güvenli `switch-case` ve `==` kıyaslaması sağlar.


4. **Swagger/OpenAPI Desteği:** Dış dünyaya (Frontend ekibine) serbest metin alanı yerine otomatik **açılır kutu (Dropdown)** sunar.


5. **MapStruct & JPA Uyumu:** DTO $\leftrightarrow$ Entity dönüşümlerinde tip birebir eşleştiği için ek çevirici kod yazma zorunluluğunu ortadan kaldırır.



---

#### 3. Projede Genelde Nerede ve Nasıl Tanımlanır?

Kurumsal katmanlı mimaride enum tipleri `model.enums` paketi altında toplanır:

* **Dosya Yolu:**
📁 `src/main/java/com/neueprojekt/itam/model/enums/AssetType.java`

* **Java Enum Kodu:**

```java
package com.neueprojekt.itam.model.enums;

public enum AssetType {
    SERVER,
    LAPTOP,
    SWITCH,
    ROUTER
}

```

---

#### 4. Katmanlarda Kullanım Örnekleri

* **DTO (Record İçinde):**

```java
public record AssetCreateRequestDto(
    String assetName,
    AssetType assetType,
    String ipAddress,
    String macAddress,
    String location
) {}

```

* **Entity Katmanında (MSSQL Eşleşmesi):**

```java
@Enumerated(EnumType.STRING)
@Column(name = "asset_type", nullable = false, length = 50)
private AssetType assetType;

```

* **Spring Data JPA Repository İçinde:**

```java
List<AssetModel> findByStatus(AssetStatus status);

```

---

#### 5. Veritabanı ve Hibernate Eşleşme (Runtime Mapping)

* `@Enumerated(EnumType.STRING)` ile veritabanına `VARCHAR(50)` olarak kaydedilir (`"LAPTOP"` metni yazılır).


* Veritabanından okunurken Hibernate `AssetType.valueOf("LAPTOP")` ile metni tekrar Java Enum nesnesine çevirir. Tanımsız bir metin okunursa `IllegalArgumentException` fırlatır.
