Veri Transfer (DTO) ve MapStruct Entegrasyonu
Dış dünyaya (React frontend veya API tüketicilerine) veritabanı nesnelerimizi (Entity) doğrudan açmamak, siber güvenlik açıklarına ve gereksiz veri transferlerine (over-fetching) engel olmak için araya DTO ve Mapper katmanları konumlandırılmıştır.

A. pom.xml Konfigürasyonu
Spring Boot'un varsayılan paketleme eklentisine dokunulmadan, Lombok ve MapStruct'ın derleme aşamasında (compile-time) uyumlu çalışabilmesi için maven-compiler-plugin projeye dahil edilmiştir.

XML
<dependency>
    <groupId>org.mapstruct</groupId>
    <artifactId>mapstruct</artifactId>
    <version>1.5.5.Final</version>
</dependency>

<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <configuration>
        <source>17</source>
        <target>17</target>
        <annotationProcessorPaths>
            <path>
                <groupId>org.mapstruct</groupId>
                <artifactId>mapstruct-processor</artifactId>
                <version>1.5.5.Final</version>
            </path>
            <path>
                <groupId>org.projectlombok</groupId>
                <artifactId>lombok</artifactId>
                <version>${lombok.version}</version>
            </path>
            <path>
                <groupId>org.projectlombok</groupId>
                <artifactId>lombok-mapstruct-binding</artifactId>
                <version>0.2.0</version>
            </path>
        </annotationProcessorPaths>
    </configuration>
</plugin>
B. DTO Sınıfları (Modern record Yapısı)
Veri transfer objeleri için daha hafif olan record yapısı tercih edilmiştir.

Java
// src/main/java/com/neueprojekt/itam/model/dto/request/UserCreateRequestDto.java
package com.neueprojekt.itam.model.dto.request;

public record UserCreateRequestDto(
    String username,
    String email,
    String password,
    String role
) {}

// src/main/java/com/neueprojekt/itam/model/dto/response/UserResponseDto.java
package com.neueprojekt.itam.model.dto.response;

import java.util.UUID;

public record UserResponseDto(
    UUID id,
    String username,
    String email,
    String role,
    String status
) {}
C. Mapper Arayüzü
Derleme anında çeviri kodlarını otomatik oluşturacak olan MapStruct arayüzü tanımlanmıştır.

Java
// src/main/java/com/neueprojekt/itam/mapper/UserMapper.java
package com.neueprojekt.itam.mapper;

import com.neueprojekt.itam.model.dto.request.UserCreateRequestDto;
import com.neueprojekt.itam.model.dto.response.UserResponseDto;
import com.neueprojekt.itam.model.entity.UserEntity;
import org.mapstruct.Mapper;
import org.mapstruct.MappingConstants;

@Mapper(componentModel = MappingConstants.ComponentModel.SPRING)
public interface UserMapper {
    UserEntity toEntity(UserCreateRequestDto requestDto);
    UserResponseDto toResponseDto(UserEntity entity);
}
